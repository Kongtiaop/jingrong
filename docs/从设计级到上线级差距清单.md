# 从"生产级设计"到"生产级可上线"差距清单

> 现状：架构/异步/安全/数据正确性已达生产级设计水准；以下为运营化最后一公里。
> 优先级：**P0 = 真正上线前必须做**；P1 = 强烈建议，发布时应有；P2 = 可后补。
> 依据：`wealth-manager` 实际代码（README 无 CI、`.env` 明文、演示密码、无**生产级**压测报告、`__pycache__` 入库等）。注：已有本地性能基准见 `docs/TESTS.md`。

## 一句话结论

从"设计级"到"上线级"，你的代码**不用重写**，缺的是运营化这最后一公里：**CI/CD + 可观测告警 + 真实压测 + 密钥/安全加固 + 部署进程管理 + 备份恢复 + 仓库卫生**。其中 P0 这 15 项做完，你就真正有底气说"这是可以上线的生产系统"。

## 4. bounded ReAct：有限轮次、工具白名单与低置信收敛 
 
解决问题：客服知识问答需要检索和解释能力，但不能允许模型无限循环、反复调用工具或在证据不足时编造答案。 
来源：app/services/customer_task_executor.py 
 
```python 
class CustomerTaskExecutor: 
    REACT_INTENTS = {\"company_info\", \"company_business\", \"faq\", \"workflow\", \"policy\", \"risk_public\"} 
``` 
 
实现说明：低风险知识任务才进入 bounded ReAct；最大迭代 3 轮、最大工具调用 3 次；工具固定为只读知识检索；每次调用记录成功状态、错误和 evidence_status。 
优化与兜底：第一次低置信度只允许一次 query refinement；仍没有足够证据时返回 needs_clarification 或转人工，不继续盲目试探，也不记录模型私有思维链。 
踩坑：检索工具返回成功不等于证据足够；必须把 citations/evidence 作为生成回答的门槛。
